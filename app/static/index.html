    How to create a bot
    1. Open the Discord Developer Portal and choose New Application.
    2. On the Bot page, choose Reset Token and copy it. Paste it above.
    3. When the bot shows as online here, use “Add the bot to a server”.
    4. Pick the channel it should post in, then send a test message.

    No privileged intents are needed. To paste a channel ID instead of picking one, turn on Developer Mode in Discord (Settings, Advanced) and right-click the channel.

    Reads each channel's public YouTube feed, so no API key or quota is involved. Set the age limit to 0 to never skip older videos.

    Instant notifications

    YouTube can push new uploads here within seconds instead of waiting for the next check. This only works if YouTube can reach this app from the internet.

    Forward just the /websub/ path through a reverse proxy or tunnel (for example Cloudflare Tunnel), then enter the public address below.
